Reset sample data?

This puts your practice tables back to how they started.

  • Rows you added or changed are removed.
  • The starting rows come back: 4 regions, 3 engines, 7 versions and 5 deployments.
  • Your saved query history is kept.

Delete this row?

Linked rows are protected: if other rows still use this one, the database will refuse. This cannot be undone, but Reset sample data brings the starting rows back.
